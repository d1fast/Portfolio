# Функция формы для Yandex Cloud Functions

Пересылает сообщения из формы на сайте в Telegram. Токен бота живёт только здесь, в переменных окружения.

## Как развернуть

1. В консоли Yandex Cloud создайте функцию: среда выполнения `nodejs18` или новее, точка входа `index.handler`.
   Код: содержимое `index.js` из этой папки (один файл, без зависимостей).
2. Переменные окружения функции:
   - `BOT_TOKEN`: токен бота из @BotFather (если старый токен попадал в переписку, сначала выпустите новый командой `/revoke`).
   - `CHAT_ID`: ваш числовой id в Telegram (можно узнать у @userinfobot). Перед этим напишите боту `/start`, иначе он не сможет вам писать.
   - `ALLOWED_ORIGIN`: адрес сайта без слэша в конце, например `https://d1fast.github.io`.
3. Сделайте функцию публичной (галочка «Публичная функция»), скопируйте её адрес вида `https://functions.yandexcloud.net/...`.
4. В репозитории сайта: Settings → Secrets and variables → Actions → Variables → добавьте `PUBLIC_FORM_ENDPOINT` с этим адресом.
   Следующий деплой включит отправку через бота. Пока переменной нет, форма открывает Telegram с готовым сообщением.

## Что делает функция

- принимает только `POST` с JSON `{ name, message, consent, lang, website }` с адреса из `ALLOWED_ORIGIN`;
- поле `website` — ловушка для ботов, если оно заполнено, сообщение молча отбрасывается;
- не больше 5 сообщений за 10 минут с одного IP;
- обрезает длинные поля, экранирует HTML и шлёт сообщение в чат `CHAT_ID`.

Бесплатного лимита Yandex Cloud Functions (миллион вызовов в месяц) для формы хватит с запасом.
