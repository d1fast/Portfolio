# d1fast.github.io

Личный сайт Савелия Лопатина (d1fast): сайты, 3D, небольшие игры и интерфейсы.
Статика на Astro, движение на GSAP, деплой на GitHub Pages.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:4321`. Сборка: `npm run build`, результат в `dist/`.
Проверка типов: `npm run check`. Скриншоты страниц для проверки: `npm run shots` при запущенном `npm run dev`.

## Как добавить кейс

1. Создайте папку `src/content/work/<slug>/` и положите в неё `ru.md` и `en.md`.
   Проще всего скопировать `src/content/work/aroma-forge/` и заменить тексты.
2. Медиа положите в `public/work/<slug>/`: обложку, видео-превью (`mp4` и `webm`, 8 секунд без звука)
   и картинки для галереи. Пути в `ru.md` и `en.md` указываются от корня сайта, например `/work/<slug>/poster.jpg`.
3. В шапке файла: `title`, `subtitle`, `year`, `order` (чем меньше, тем выше в списке), `role`, `stack`,
   `cover`, `video`, `media`. Тело файла: разделы «Задача», «Решения», «Результат».
4. Запушьте в `main`. Страница кейса появится по адресу `/work/<slug>/` и `/en/work/<slug>/`.

Кейс с `draft: true` в шапке не попадает на сайт.

## Тексты

Все тексты интерфейса лежат в `src/i18n/ru.ts` и `src/i18n/en.ts`. Контакты и адреса в `src/config.ts`.

## Деплой

Каждый пуш в `main` собирает сайт и выкладывает его на GitHub Pages
(`.github/workflows/deploy.yml`). В настройках репозитория у Pages должен быть источник «GitHub Actions».
Адрес зависит от имени репозитория: для `d1fast.github.io` это корень домена, для любого другого имени подпапка `/<имя>/`.

## Форма обратной связи

Сообщения из формы уходят в Telegram через небольшую серверную функцию, код и инструкция в `server/yandex-cloud-function/`.
Пока адрес функции не задан, форма открывает Telegram с готовым текстом сообщения.
Чтобы включить отправку через бота, добавьте в настройках репозитория переменную
`PUBLIC_FORM_ENDPOINT` с адресом функции. Токен бота хранится только на сервере функции.
